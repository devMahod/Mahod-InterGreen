# התחלה מהירה — דוד

> **הגרסה הנוכחית אינה מציירת אוטומטית את מסלולי התנועה. הגיאומטריה הקיימת ב-DWG היא קלט
> הנדסי שהמהנדס מכין. מרגע שהמסלולים קיימים, הכלי מבצע אוטומטית את איתור הקונפליקטים,
> המדידות, החישובים, הבקרה והמטריצה/Excel.**
> (ציור מסלולים בסיוע הכלי — Assisted Drawing — הוא תכולה עתידית בלבד, לא חלק מהפיילוט.)

הזרימה הקצרה ביותר:

```text
פתיחת DWG → INTERGREEN → Setup → Validate → Analyze → Review/Show → Export Excel
```

1. **התקנה** — לפי `README_INSTALL_HE.md` (פעם אחת).
2. **פתיחת שרטוט** — שרטוט הבין-ירוקים הרגיל (שכבות `intergreen_*` + `intergreen_stopline`).
3. **`INTERGREEN`** — נפתחת פאלטת "MAHOD INTERGREEN".
4. **Setup** — בחירת קובץ האקסל של הפרויקט; אם השרטוט ללא יחידות (INSUNITS=Unitless) —
   אישור חד-פעמי שהשרטוט במטרים. הכול נשמר ליד ה-DWG בקובץ `.intergreen-project.json`
   (לא שואלים שוב).
5. **Validate** — רשימת תנועות, מעברים, שגיאות והתראות. שגיאה חוסמת רק את מה שנוגע לה.
6. **Analyze** — חישוב כל הקונפליקטים, כל נקודות המועמד (ללא הגבלת 4), והמטריצה.
   קובצי `analysis.json` / `validation.json` נכתבים ליד השרטוט.
7. **בחירת שורה → Show in drawing** — זום והדגשה של כל נקודות הקונפליקט; אדום = הנקודה
   הקובעת. `IG_CLEAR_QA` מנקה.
8. **Export Excel** — עותק של קובץ האקסל (המקור לא נפגע!) עם CD/ED מהמנוע, גיליון
   `MAHOD Engine Results` (כל הנקודות + עקיבות מלאה) וגיליון `MAHOD Matrix Status`.
