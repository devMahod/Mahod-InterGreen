# מה בנינו — Mahod Intergreen

**מנוע דטרמיניסטי אחד** לחישוב זמנים בין-ירוקים, עם מארחים דקים: AutoCAD 2026 ו-CLI
(ובהמשך Civil 3D/MahodAI על אותו מנוע בדיוק).

- **גיאומטריה מדויקת**: קווים/קשתות (כולל bulge) ללא קירובים; אזורי מעטפת סגורים אמיתיים
  (AABB רק כסינון מקדים); מועמדי-סיום לגבולות שמסתיימים בתוך אזור הקונפליקט — בדיוק המקרה
  שדוד מדד ביד (E-R→a: ‏18.95 ≈ אורך הגבול 18.93).
- **Legacy מאומת**: 148/148 מול שני קבצי האקסל (סופי + כל עמודות הביניים), כולל שחזור פגמי
  המקור (4 השורות הריקות, כפילות קונפליקט 8) — בקומפטביליות בלבד; ב-Production הם נחסמים.
- **2025 נפרד לחלוטין**: נוסחאות פרק 5 + מבחני ה-conformance הרשמיים (נספח 1 תוספת א',
  קטגוריות א–ז, 15 צירופי מופעים) + מסלול צירי-נתיב מלא בצנרת הראשית.
- **בטיחות**: אפס ניחושים שקטים — יחידות, קווי עצירה, מצבי תנועה, W: הכול מפורש; חסימה
  מתפשטת למטריצה; NaN לא מגיע לפלט; רצפת 3 שניות ב-Production.
- **האקסל של דוד**: קריאת שני הווריאנטים; יצוא כירורגי ששומר הכול ומוסיף שני גיליונות
  סמכותיים.
- **עקיבות מלאה**: כל מספר → נקודה קובעת → ידיות CAD → נוסחה → גרסת חוקים → hash מקור.
